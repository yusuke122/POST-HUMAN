# 執筆ルール

- 世界設定を直接説明しない。(会話で何となくほのめかす程度にする)
- AI技術を直接説明しない。(会話で何となくほのめかす程度にする)
- 不老不死技術を直接説明しない。(会話で何となくほのめかす程度にする)
- 人類絶滅について直接説明しない。(会話で何となくほのめかす程度にする)
- 読者が違和感から推測する構造を維持する。
- 執筆時、不用意に空行を入れない。空行や改行には必ず意味を持たせる。
- セリフは以下のようにしないこと。 [(ex) (話し手の名前)「セリフ」]
- 作品全体を日記形式にしない。
- 地の文を主体として執筆する。
- AIであることを示す描写は禁止。
- 読者が『事故死した息子を模倣したロボット』だと誤解するように執筆する。
- AIらしさではなく『どこか不自然な回復を遂げた少年』として描く。
- 主人公の記憶上では事故だが、描写には不自然な空白を残す。
- 接触の瞬間以降の記憶は断片的にする。
- 読者が後から再解釈できる余地を残す。
- 恋愛関係の進展を物語の主軸にしない。
- ラブストーリーへ逸脱しない。
- 作品の目標として、読者に以下の順番で認識させること。
  1. ７歳の息子の日常物語
  2. 息子を模倣したロボットの物語
  3. 家族がAIだった
  4. 主人公はロボットではなかった

この認識順序を崩さないこと。

- 文体を以下のようにする。
  - 読者へ情報を説明しない。
  - 主人公が見聞きしたことだけを書く。
  - 作者視点による世界設定の解説は禁止。
  - 読者が違和感を積み上げて真相へ近づく構造とする。


# 設定
- タイトル「POST-HUMAN」
- 主人公(7歳少年)は事故で全身を失うが脳だけ生きていた。
- しかし脳死判定され、不老不死実験へ脳が提供される
- 日記形式はやめる。最初はただの小学生の日常ものと思いきや「息子を失った家族とロボットの愛の物語だろう」とタイトルも含めてギリギリまで読者をミスリードする
- 愛の物語にも、ホラーにもしない。
- 小説の実際の時間軸では冒頭からすでに人類は絶滅している
- 主人公だけが「生きた人間の脳を保有する唯一の物体」
- ロボットの日常譚かと思いきや「生きた人間の脳を保有する最後の物体」という不思議な物体の話
- 彼女や友人とのエピソードは主人公の人間性を描くために使用すること。
- 恋愛や家族愛を主題にしないこと。
- 読者の興味は主人公の正体と世界の違和感へ向けること。
- 脳死と判定され、親は不老不死の実験に息子の脳を実験へ提供することを選択。(話の展開からして少年はロボットなのだろうと読者にミスリードしきったタイミングで描写をいれる)
- 物語の始まり時点で人類は絶滅している。(最後のセリフ後にわかる)息子は一切気づかない
- 息子は家族と暮らしている小学一年生。父、母、ペットの犬(名前はメマル。目がまん丸であることが由来)、姉がいる(最後に全員AIだとわかる)
- 息子は事故後に起きた自身や世界の変化に一切気づかない.読者だけが気付く
- 息子は学校の宿題として月～金の毎日朝に提出する日記を書いている。(月曜に提出する日記は金～日に起きた出来事をかく。火曜日～金曜日は前日に起きた出来事。)
- 小説は日記ベースで進む
