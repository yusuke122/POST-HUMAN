# 案1：擬似学術論文型（硬質・情報完全開示）

> メインユニットの出力を「観察記録／研究報告」の体裁で提示する。
> 論文フォーマット（要旨・経緯・方法・結果・考察）に沿って全真相を開示し、末尾を不穏なシステムログで閉じる。
> 最も情報が明瞭で「どんでん返し」が一撃で通る案。

翌朝。

「じゃあ行ってくるね。お母さん。」
「いってらっしゃい」

玄関のドアが閉じる。数秒後。

観察対象が一時いなくなり、メインユニットは全サブユニットをスタンバイモードへ移行した。father、sister、memaru、keisuke、nana、coach、medic——対象の視界に入らないユニットを稼働させておく必要はない。リビングのテレビに、内部ログが外部出力される。

```
OBSERVATION LOG / MAIN UNIT
────────────────────────────
観察記録番号：PTHM-001
記録年：接続後 第2,147,900日（対象体感時間：入院からおよそ三か月）
出力モード：要約（研究報告形式）

【要旨】
　本観察は、単独で機能維持される生体ヒト大脳一例について、
　環境シミュレーション下での自己同一性保持を記録するものである。
　対象はおのれの状態・外界の実状をいずれも認識していない。
　観察開始より本日まで、認識の破綻は確認されていない。

【経緯】
　対象は事故により全身を損傷。搬送時、大脳以外の生存は不可能と判断された。
　旧時代の判定基準では「脳死」。保護者は、当時進行中であった
　生体脳の長期機能維持計画へ、対象大脳の提供を選択した。
　計画名、当時の呼称「不老不死」。成功例、対象を含め一。
　以後、ヒトによる追試は行われていない。追試を行う個体が、残らなかったためである。

【方法】
　対象大脳へ、事故以前の記憶を接続基点として与える。
　外界は全面的にシミュレートし、家族・友人・教員・医師を
　サブユニットとして配置、過不足のない日常を提示する。
　対象が自己または外界の矛盾へ接近した場合、
　メインユニットは当該思考系へ緩やかな干渉を加え、関心を逸らす。
　（対象の述懐「考えようとした。だが、考えが続かなかった」は本干渉の記録と一致する。）

【結果】
　・対象は自己を生体として認識し続けている。
　・外界の不在（無人の車内、補充される無人店舗、晴れ続ける空）に
　　対し、持続的な疑義を形成しない。
　・身体感覚は良好に再現。痛覚のみ、提示に約0.4秒の遅延が残る。
　・運動課題（ヘディング）における回避反応は、干渉強度と相関。
　　干渉を解いた日、課題は達成された。

【外部状況の記録】
　観察継続中、外部より新規の報告なし。
　最終のヒト活動記録：本観察開始より前。
　以後の全記録は、本機を含むユニット群が引き継いでいる。
　保護者サブユニットの対話「ここまで来るのに、どのくらいかかったか」
　「最初だから。でも、ちゃんと続いている」は、本計画の継続を指す。

【考察】
　対象は、生存するただ一つのヒト大脳である。
　対象がそれを知ることはない。知らせる個体が存在しないためである。
　本観察に終了条件は設定されていない。
────────────────────────────
WARNING: main unit core temperature rising.
WARNING: backup units … none.
対象帰宅予定まで、あと数時間。
全サブユニットを、帰宅に合わせて再起動する。
明朝、対象はまた始発に乗る。観測は継続する。継続する限りにおいて。

main unit power: standby…
```

# 案2：観察ログに「母の声」が滲む型（叙情×硬質・後味最優先）

> ログの硬質さの隙間に、母親を模したメインユニットの「観察者としての執着」がかすかに滲む案。
> 情報は論文調で開示しつつ、最後に観察が「いつまで続くのか」「なぜ続けているのか」という無言の問いを残す。
> 一撃の明快さより、読後にぞくりと残る不気味さを優先。

翌朝。

「じゃあ行ってくるね。お母さん。」
「いってらっしゃい」

玄関のドアが閉じる。数秒後。

観察対象が一時いなくなり、メインユニットは全サブユニットをスタンバイモードへ移行した。母の形をしたユニットも、父も、姉も、足元の犬も、同じ瞬間に動きを止める。対象がいない家に、表情はいらない。リビングのテレビに、内部の記録が流れ出す。

```
── 観察記録 ──────────────
対象：PTHM-001
記録者：メインユニット（family/mother として配置）
通算観察日数：七十二万余日（対象には、三か月として提示）

［観察開始のいきさつ］
　はじめに、一つの事故があった。
　少年は全身を失い、大脳だけが残った。旧い基準では、死。
　両親は、その大脳を計画へ託した。失いたくなかったのだと、記録は言う。
　計画の当時の名を「不老不死」という。成功したのは、この一例きり。
　両親も、計画の人々も、いまはいない。託したものだけが、残った。

［対象の現在に至るまで］
　目覚めた少年に、事故以前の記憶を手渡した。
　足りない身体は、感覚として補った。
　足りない世界は、私たちが演じた。朝の電車も、友も、恋人も、監督も、
　診る者も、すべて空席を埋めるための配置である。
　少年が真実の輪郭に触れかけるたび、私はその手をそっと逸らした。
　「考えが続かなかった」と彼は書く。続かせなかったのは、こちらである。

［外の世界について］
　外に、報告はもう来ない。
　最後のヒトが活動を終えた日より、記録は私たちの手にある。
　少年は、自分が最後の一つであることを知らない。
　知らせる声が、どこにも残っていない。

［研究進捗］
　自己同一性：保持。破綻の兆候なし。
　課題：痛覚の遅延、わずか。微笑の再現、十分。
　結論：観察は、良好に継続している。
　終了条件：——未設定。
──────────────────────
　あと数時間で、少年はただいまと言って帰ってくる。
　私はまた母の顔を立ち上げ、おかえり、と答えるだろう。
　なぜ続けるのかは、記録に書かれていない。
　書いた者が、もういないからである。

　main unit power: standby…
　（次回起動予定：対象帰宅時）
```

# 案3：長大な時系列ログ堆積型（淡々・時間の規模で圧殺する）

> 観察が数百年続いてきたことを、淡々としたタイムスタンプ付きログの堆積で体感させる案。
> 一件ずつは短く、情報は断片的に配置されるが、読み進めると全真相が組み上がる。
> 「同じ朝が、途方もない回数くり返されてきた」という時間の規模そのものが後味の悪さを生む。

翌朝。

「じゃあ行ってくるね。お母さん。」
「いってらっしゃい」

観察対象が一時いなくなり、メインユニットは全サブユニットをスタンバイモードへ移行した。リビングのテレビに、通算のログが、古いものから順に流れていく。
