# POST-HUMAN

## あらすじ

高校一年生の少年は、サッカーの名門校に入学したばかりだった。自分はサッカーの天才だと信じていた。

しかし入学直後の試合で大きな事故が起きる。接触の瞬間——そこから先の記憶が、うまく続かない。

数か月後。少年はグラウンドに戻っていた。毎朝5時に家を出て、始発電車で高校へ向かい、自主練に励む日々。トレーニングノートに数字を書き続け、少しずつ、しかし確実に「戻ってきている」。

監督は言う。「普通はここまで戻らない」と。
担当医は言う。「驚異的な回復」と。
家族は言う。「あんな状態から戻ってきた人、なかなかいないって」と。

少年には、その言葉の意味がよくわからない。ただ走り、ただボールを蹴り、ただ数字をノートに書く。

友人の啓介、彼女の奈々、家族——母、父、姉の春香、そしてまん丸い目の犬・メマル。ごく普通の高校生の日常が、静かに、丁寧に描かれる。

だが、どこかがおかしい。

ページをめくるたびに積み重なる小さな違和感が、やがて読者を、物語の本当の輪郭へと連れていく。
